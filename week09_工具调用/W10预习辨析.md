# W10 预习：三者辨析（W9课后作业3）

1. **Function Calling（模型侧机制）**：是模型自身具备的一种能力，它能在对话中输出“我想调用某个函数及参数”的意图（JSON），但真正执行函数的是外部程序。
2. **MCP（工具侧协议）**：是一种标准化的通信协议。它规定了工具该如何标准化地接入不同的 AI 应用，让工具可以跨平台复用。
3. **普通 API 调用**：是程序员写死的固定请求，没有大模型自主决策的成分。

**希望 MCP 帮我接上的 2 个外部工具**：
1. 实时网络搜索 API（用于获取最新资讯）。
2. 学校的教务系统查询 API（用于直接查询学生成绩）。
