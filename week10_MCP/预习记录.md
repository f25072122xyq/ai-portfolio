## 3. 三者辨析
- **Function Calling** 是模型侧机制，解决大模型如何输出“想调用什么工具”的指令。
- **MCP** 是工具侧协议，解决不同工具如何以标准接口接入不同 AI 应用的问题。
- **普通 API 调用** 是程序员写死的固定请求，没有大模型自主决策的成分。
