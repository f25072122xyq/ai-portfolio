# 开源项目阅读笔记 (read_notes.md)

1. **2-Step RAG 是什么**：它是指检索总是发生在生成之前，模型调用次数有上限，延迟可预期，非常适合 FAQ 和基于固定文档的问答。
2. **llm-universe C3 做了什么**：C3 章节主要讲解了词向量及向量知识库，包含 Embedding API 的使用、数据处理的读取清洗与切片，以及如何搭建并使用向量数据库。
3. **llm-universe C4 做了什么**：C4 章节主要讲解了如何将 LLM 接入 LangChain，基于 LangChain 搭建检索问答链，以及如何使用 Streamlit 部署知识库助手。
