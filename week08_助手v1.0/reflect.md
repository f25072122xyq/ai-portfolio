# 开源项目对照反思 (reflect.md)

1. **我的 rag_qa.py 与官方 2-Step RAG 差在哪一步？**
我的 rag_qa.py 与官方最大的差距在于“向量化入库”这一步。官方用的是标准向量库，而我为了快速跑通，采用的是“直接把整段资料塞进提示词”的简化做法，没有真正去计算向量相似度。

2. **如果要从 2-Step 走到 Agentic RAG，我需要先补上什么能力？**
我需要先补上“工具调用（Function Calling）”的能力。需要让 AI 自己判断是否需要调用 `retrieve()` 去查资料，这就需要学习 W9 的工具调用技术。

3. **为什么只能参考思路、不能复制代码？这与 .env 红线有什么共同点？**
没有 LICENSE 文件意味着默认“保留所有权利”，直接复制代码就构成了学术剽窃。这与 .env 不入仓一样，共同点在于：都是底线与规则意识。不复制代码是尊重知识产权，不泄露密钥是保护隐私安全。
